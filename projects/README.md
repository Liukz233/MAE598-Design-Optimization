# Course Projects

This directory contains the five graded team projects for MAE 598/494 Design Optimization.

## Standard layout

Each project workspace uses the following structure:

~~~text
project/
├── README.md       # Scope, method, results, and reproduction notes
├── notebooks/      # Exploration and demonstrations
├── src/            # Reusable implementation
├── figures/        # Report-ready visualizations
├── results/        # Small, curated numerical results
└── report/         # LaTeX source and final report.pdf
~~~

Do not add instructor-owned problem statements, lecture slides, solution sets, or exam materials to this public repository. Summarize the task in your own words and include only original work.
