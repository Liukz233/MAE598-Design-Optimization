# Presentation

Store slides and supporting materials here when OptiForge is assigned or volunteers for an in-class presentation.

Recommended files:

~~~text
presentations/
├── slides.pptx
├── slides.pdf
├── figures/
└── README.md
~~~

The README should record the presentation topic, date, speaking plan, and any live-demo instructions. Commit only original presentation content; do not redistribute instructor-owned course materials.
