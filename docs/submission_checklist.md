# Project Submission Checklist

Use the official assignment brief as the source of truth. Project 1 requires a single publicly accessible Markdown report; future briefs may modify the required format.

## Official requirements

- [ ] The official assignment page is linked from the project README and report.
- [ ] Every required section and rubric item is mapped to a report section.
- [ ] File format, public-access rule, Canvas submission item, deadline, and presentation requirement are confirmed.
- [ ] No unverified requirement has been copied from another project.

## Report content

- [ ] The primary report is saved at the stable path `report/report.md`, unless the brief specifies otherwise.
- [ ] The problem and real-world or engineering motivation are understandable to a nonspecialist.
- [ ] Design variables are distinguished from states and fixed parameters.
- [ ] Variable types, units, dimensions, and bounds are given.
- [ ] The objective is an explicit mathematical expression with min/max direction.
- [ ] Equality constraints, inequality constraints, and bounds are explicit and explained.
- [ ] The problem classification is justified from the mathematical structure.
- [ ] Assumptions, simplifications, omitted effects, and limitations are stated.
- [ ] All bracketed template prompts and placeholder links have been removed.
- [ ] References and external data sources are cited.

## Computational work

- [ ] The code or notebook runs from a clean environment.
- [ ] Initialization, parameters, random seeds, and stopping criteria are recorded.
- [ ] Figures have readable labels, units, legends, and captions.
- [ ] Reported results are traceable to committed code and data.
- [ ] Results are interpreted, not merely displayed.
- [ ] Large datasets and checkpoints are excluded or linked appropriately.

## GitHub rendering and URLs

- [ ] Display equations render correctly with GitHub Markdown math.
- [ ] Relative links to figures, code, notebooks, and results work.
- [ ] The repository and report links work in a signed-out browser.
- [ ] The latest changes are on `main`.
- [ ] No credentials, private data, exam content, or instructor-owned files are committed.
- [ ] If an immutable submission is needed, the final commit permalink is recorded.
